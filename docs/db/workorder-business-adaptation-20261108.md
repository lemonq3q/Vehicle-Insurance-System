# 工单合表关联业务适配检查（2026-11-08）

最终结构：workorder 合并 underwriting/payment，quote 合并 commission；三种起期在主表。按用户确认，非车险只记录起期，不增加自动续保跟进。

| 关联业务 | 核查与处理结果 |
| --- | --- |
| 详情、报价、承保、失败反馈、支付确认 | 读写切换到两表；报价字段白名单，完整承保事务保存保单、政策、收款和附件 |
| 工单新增、基础资料、证件与险种 | 新增保留自动接单和商户收款快照；基础资料白名单保护已确认保单和政策，增加非车险预填起期；待承保后起期在承保表单维护 |
| 派单、接单、处理人和列表查询 | 原主表ID、处理人、状态字段均保留；已核查现有调用，权限及派接单入口继续使用原主表字段 |
| 续保列表、数量、提醒重置、按险种跟进 | 商业/交强起期和独立周期保留，查询去除旧阶段表；非车险不参与提醒，已有关闭/流失/续保状态不重置 |
| 企业门户续保统计 | 修正创建日推算，改用真实商业/交强起期和自然周年，排除本周期已处理事项，两险种按工单去重；保留30/7天门户窗口 |
| 日终利润、处理工单量 | 改读主表完成时间和 quote 上下游四类政策金额；人工固定金额不重算，历史统计宽表不批量改写 |
| 门户/监控经营数据 | 继续消费既有每日统计宽表；其字段和企业汇总接口不因业务表合并改变 |
| 批量导入、模板下载 | 101列动态模板与JSON共用契约，兼容旧93列；新增三类公司/终期、非车险号码/起期及其校验，非车险号码参与已完成状态恢复；保留逐行事务和无附件历史导入 |
| 工单Excel导出 | 新增三类保单公司、号码、终期及非车险起期；兼容旧计算方式空值，并修正上游车船税误取下游金额 |
| 文件上传、替换、下载、无主文件清理 | 非车险保单与其他单证统一使用 `acceptInsuranceOther`，每单最多六份；历史 `acceptInsuranceNonMotor` 读取时合并、重新承保提交时归一化；校验本企业文件并拒绝其他工单占用，仍有有效引用的文件不标记无主 |
| 日常逻辑删除归档、企业到期资料迁移 | 清除旧三表清单，主表/金额表的新字段随共有列归档；迁移备份不加入日常自动清理 |
| SaaS通用归档发现 | 核对按在线/归档表配对发现方式，与新主表/金额表兼容；无归档配对的迁移备份不会自动清理 |
| 套餐用量、工单周期超额扣费、套餐提醒 | 只使用未变的主表ID、enterprise_id、created_at、deleted、last_overage_billing_date，无需改变计费口径；迁移复制保留原索引和ID自增高水位 |
| 租户隔离、编号生成 | 租户表清单去掉退役表；保留主表编号唯一约束，阶段写入显式企业条件，并用工单行锁避免并发补建重复金额记录 |
